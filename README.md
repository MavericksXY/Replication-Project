# Replication: "Empirical Properties of Diversion Ratios"

Replication of Conlon, C. and J. H. Mortimer (2021), "Empirical Properties of Diversion Ratios"
([paper](https://chrisconlon.github.io/site/diversion.pdf)), using the authors' replication package
([chrisconlon/DiversionReplication](https://github.com/chrisconlon/DiversionReplication)).

The authors' code in `code/` is unchanged, so the outputs reproduce the published tables and figures.
This repository adds a one-click runner (`run_all.py`), a working package environment, and notes on
issues found while replicating.

## Repository structure

```
├── run_all.py      # one-click runner (added)
├── code/           # authors' scripts (unchanged)
├── data/raw/       # BLP (1999) autos and Nevo (2000) cereal data
├── tables/         # generated LaTeX tables
└── figures/        # generated figures (PDF)
```

Estimation results (`data/dict/`) are not included: they are large and are regenerated on the first run.

## Requirements

The 2021 code does not run on current package versions: pandas 2 removed `DataFrame.append`, and
matplotlib 3.8 removed the `seaborn-whitegrid` style. The original `run_all.sh` also installs the latest
pyblp from GitHub, which is years newer than the code. Use a Python 3.9 environment instead:

```bash
conda create -n diversion python=3.9 -y
conda activate diversion
pip install numpy==1.23.5 scipy==1.9.3 pandas==1.5.3 matplotlib==3.5.3 tabulate==0.9.0 pyarrow==11.0.0 brotli statsmodels==0.13.5 pyblp==0.13.0
```

`statsmodels` is required by `tab7_wtp.py` but missing from the original `requirements.txt`.
Tested on macOS (Apple silicon) with Python 3.9.

## How to run

```bash
python run_all.py
```

Or open `run_all.py` in VS Code and click Run. The script:

- checks the Python and package versions before anything slow starts;
- estimates the 12 demand models (saved in `data/dict/`), skipping any already saved, so a stopped run
  resumes where it left off;
- runs the table and figure scripts from inside `code/`;
- limits numpy's math library to one thread (see Speed below).

Set `RUN_ESTIMATION = True` at the top of `run_all.py` to re-estimate everything, or `False` to skip
estimation.

## Replication notes

**Results.** Figures 1–4 match the published figures. For example, diversion from the Honda Accord to
the Toyota Camry is 3.25% for a small price change and 3.83% for second choice, as in the paper.

**Speed.** By default, numpy's math library (OpenBLAS) starts one thread per core. pyblp performs many
small matrix operations, and on a many-core Apple chip the threads spent most of their time
coordinating: one BLP model took 49 minutes at about 1,700% CPU. With `OPENBLAS_NUM_THREADS=1`
(set by `run_all.py`), two comparable models took 1.4 and 2.8 minutes.

**Issues found in the original code** (not corrected here, so outputs match the paper):

1. **Table 6.** In `tab56_diversion.py`, the BLP block assigns `a3` twice and never sets `a4`. As a
   result, the BLP "Logit" top-5 row shows the BLP nested-logit values, and the BLP "Nested Logit" row
   reuses the Nevo values. The published Table 6 shows the same duplicated numbers (19.06, −6.48) for
   both datasets.
2. **Table 3 standard errors.** For the random-coefficient BLP models, `get_params_blp` in
   `aux_table_functions.py` reports `beta_se[1]`, the standard error of HP/weight, under price/income.
   The published Table 3 reports the price/income standard error (e.g. 5.847), so this row may differ
   from the paper.
3. **Figures 1–2 weights.** `aux_compute_mpc.py` adds `results.beta[0][0]` to each consumer's price
   coefficient. In the BLP model this is the constant term, not a mean price coefficient, which shifts
   the "marginal price change" weights in the histograms.
4. **Figure B.1.** In `tab7_wtp.py`, the Nevo price coefficient adds `sigma_price` once more than the
   model implies, which shifts the Nevo density.
